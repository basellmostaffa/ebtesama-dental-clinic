# Ebtesama Dental Clinic

A production-ready Arabic RTL landing page for **عيادة ابتسامة لطب الأسنان**, a fictional dental clinic in Cairo. Built with React, Vite, Tailwind CSS, and lucide-react.

## Features

- Fully responsive single-page layout for mobile, tablet, and desktop
- Arabic RTL typography with the Cairo Google Font
- Sticky navigation, smooth scrolling, and subtle scroll reveal animations
- Hero, services, clinic benefits, doctors, pricing, testimonials, FAQ, booking, contact, and footer sections
- Client-side Egyptian phone validation and booking success state
- Accessible buttons, labels, focus states, semantic sections, lazy-loaded imagery, and reduced-motion support
- Static deployment friendly for Vercel (no backend required)

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Deploy the repository to Vercel with the default Vite settings. The output directory is `dist`.
